# Contributing

We welcome contributions to LOCCA! This guide will help you get started.

## Development Setup

1. Follow the [installation guide](../getting-started/installation.md)
2. Set up development environment
3. Install pre-commit hooks: `pre-commit install`

## Code Style

Follow our coding conventions:

- Use type hints for all parameters and return types
- Format code with `ruff format`
- Lint with `ruff check --fix`
- Use f-strings for string formatting

## Testing

- Write tests for new features
- Run the full test suite: `uv run task test-all`
- Aim for high test coverage

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests and linting
5. Submit a pull request
6. Wait for review

## Issue Reporting

- Use GitHub issues for bugs and features
- Provide detailed reproduction steps
- Include environment information
- Use appropriate labels

## Documentation

- Update docs for any user-facing changes
- Add API documentation for new modules
- Keep README and guides current

## Community

- Be respectful and inclusive
- Follow the code of conduct
- Help other contributors

## Getting Help

- Check existing issues and documentation
- Ask questions in discussions
- Join our community chat

## Recognition

Contributors are recognized in:
- CHANGELOG.md
- GitHub contributors list
- Release notes

Thank you for contributing to LOCCA!
